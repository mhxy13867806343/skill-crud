# skill-crud

Portable CRUD skill for ChatGPT and Codex.

## Contents
- `SKILL.md`: shared skill instructions
- `config/rules.json`: persistent user-authored rules data
- `references/command-reference.md`: command examples and semantics

## Install
- Codex: copy the `skill-crud` folder into `~/.codex/skills/` (or another supported skills directory).
- ChatGPT: import/upload the skill bundle through the Skills management surface if available. If your client does not expose Skills, keep this bundle as the portable source; it will not automatically grant access to all chats or quota data.

The bundle is created, but it has **not** been installed into your Mac or ChatGPT account, and it has **not** been pushed to GitHub/Gitee.
